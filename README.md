# 捡影 Pickview

> 捡起散落在硬盘里的影像，让浏览重新变得轻盈。

捡影是一款本地优先的桌面图片浏览器。选择一个文件夹，它会在几秒内整理目录与图片，用自适应瀑布流呈现内容，并提供覆盖整个窗口的无损大图查看、全工作区模糊搜索、浅色/深色主题与半透明界面。

当前版本为 **v0.0.2**，提供 macOS 与 Windows 安装包。

[下载最新版](https://github.com/howoow/pickview/releases/latest) · [查看 v0.0.2 发布说明](https://github.com/howoow/pickview/releases/tag/v0.0.2)

## 产品定位

捡影不是素材管理平台，也不是云端相册。它只做一件事：让你快速打开本地图片文件夹，安静、顺畅地浏览其中的内容。

- **文件夹即工作区**：无需导入、复制或重新整理已有照片。
- **本地优先**：图片读取、尺寸解析、缩略图生成与搜索都在本机完成。
- **专注浏览**：干净的三栏界面，紧凑侧栏、低干扰路径面包屑和克制的动效。
- **为速度设计**：目录并发扫描、虚拟滚动、缩略图缓存与 Worker 搜索。

## 主要功能

### 工作区与目录树

- 选择任意本地文件夹作为工作区，递归扫描子目录中的图片。
- 目录树展示每个文件夹的直接图片数与子目录图片总数。
- 面包屑显示当前路径，可快速返回上级目录。
- 记住最近打开的 5 个工作区。

### 自适应图片浏览

- 根据图片真实宽高自动排布瀑布流，也可切换为整齐网格。
- 缩略图提供“小 / 中 / 大”三档尺寸，不打断浏览节奏。
- 支持按名称、最近修改时间、文件大小排序。
- 仅渲染视口附近的图片卡片，大目录滚动依然轻快。

### 沉浸式大图查看

- 点击图片，从缩略图以共享元素过渡展开到全窗口查看器。
- 查看器支持滚轮无级缩放、100% 状态下拖动、双击逐级放大、按钮缩放与适应窗口。
- 双击按 `100% → 150% → 300% → 100%` 平滑切换，并始终以鼠标位置为缩放中心。
- `Esc` 立即退出查看器，关闭时回到原缩略图位置。
- 原生支持格式直接读取原文件；HEIC、TIFF 等兼容格式在本地解码为 PNG 预览，避免有损二次压缩。
- 左右方向键按当前顺序切换图片，查看器会显示尺寸、文件大小与修改日期。

### 全工作区搜索

- 输入即搜索，支持文件名与相对路径的模糊匹配。
- 搜索索引在独立 Web Worker 中处理，不阻塞界面滚动与预览。
- 匹配结果按相关度排序，适合图片数量很多的工作区。

### 外观与体验

- 浅色、深色与跟随系统三种主题。
- 界面透明度可在 35%–100% 之间调节，侧栏、工具栏与浮层底色会同步变化，图片始终保持不透明。
- 侧栏收起/展开、查看器开合与设置面板均带轻量过渡，并遵循系统的“减少动态效果”设置。
- macOS 使用原生窗口材质与交通灯布局；Windows 使用对应的窗口与安装体验。
- 启动后静默检查新版本；只有发现更新时才在设置按钮上显示一个小圆点，不弹窗打扰。

## v0.0.2 更新摘要

- 优化点击图片时的展开动画：先用已加载的缩略图完成转场，再在后台解码原图，减少大图打开瞬间的掉帧。
- 100% 缩放状态也可直接拖动画面；鼠标在图片区域始终显示抓手光标。
- 双击缩放改为 `100% / 150% / 300%` 三档平滑循环，滚轮仍保留无级缩放。
- 修复透明度滑块不生效的问题，并扩大透明度可调范围。
- 更新检查改用 GitHub Release Atom 源，避开匿名 API 限额；增加超时、自动重试与本地缓存。

## 版本更新

捡影采用轻量的更新提醒，而不是强制升级：

- 启动约 5 秒后静默读取 GitHub 最新 Release 源，24 小时内最多检查一次；网络失败不会打扰浏览。
- 发现新版本时，设置按钮出现小圆点；打开“界面设置”即可看到版本号与下载入口。
- 也可以在“界面设置 → 检查更新”手动检查，或使用 macOS 应用菜单 / Windows“帮助”菜单。
- 下载会通过默认浏览器打开 GitHub Release 中与当前系统和架构匹配的安装包。
- 请求遇到 `429` 或 GitHub 临时繁忙时会自动重试；成功结果会缓存一天，网络不可用时继续展示上次检查结果。
- 当前版本尚未签名，因此不做应用内静默替换安装；未来完成签名与公证后，再接入增量更新。

更新检查只会读取公开的 GitHub Release 源，不会上传工作区、图片或使用记录。为了让匿名检查生效，GitHub 仓库与 Release 需要保持公开。

## 下载与安装

请前往 [GitHub Releases](https://github.com/howoow/pickview/releases/latest) 下载对应安装包：

| 平台 | 安装包 | 适用设备 |
| --- | --- | --- |
| macOS | `.dmg` | Apple Silicon（文件名含 `mac-arm64`）或 Intel（含 `mac-x64`） |
| Windows | `.exe` | Windows 10 / 11 64 位（文件名含 `win-x64`） |

> **v0.0.2 暂未进行代码签名。** macOS 可能提示“无法验证开发者”，Windows 可能触发 SmartScreen。应用本身不包含恶意行为，可按下方方式首次放行。

### macOS 首次打开

1. 打开 `.dmg`，将“捡影”拖入“应用程序”。
2. 在“应用程序”中右键点击“捡影”，选择“打开”。
3. 若仍被拦截，前往“系统设置 → 隐私与安全性”，点击“仍要打开”。

### Windows 首次打开

1. 运行安装程序；若出现 SmartScreen，点击“更多信息 → 仍要运行”。
2. 按安装向导完成安装并启动“捡影”。

### Windows 卸载

- 打开 Windows“设置 → 应用 → 已安装的应用”，找到“捡影”并选择“卸载”。
- 也可以在捡影的“界面设置”底部点击“卸载捡影…”，直接启动卸载程序。
- 卸载会移除应用本体、缩略图缓存、最近工作区与界面设置。

## 支持格式

- **原生直接读取**：JPEG、PNG、WebP、GIF、AVIF、BMP、SVG。
- **本地转码预览**：TIFF、HEIC、HEIF、JXL。macOS 会在需要时调用系统 `sips` 兜底；Windows 使用内置解码能力，HEIC/HEIF 的覆盖率仍取决于系统与编解码器支持。
- 缩略图为本地生成的 JPEG 缓存；大图查看优先使用原文件，不经过有损再压缩。
- 超大图片在兼容格式预览时可能按显示需要进行尺寸限制，以控制内存占用。

## 性能与隐私

- 目录扫描采用受控并发，只读取文件头和尺寸信息，不预先解码整张图片。
- 缩略图按需生成并缓存在系统用户数据目录，重复浏览无需重新计算。
- 图片网格采用虚拟化渲染，只保留视口附近节点。
- 搜索不阻塞主线程，索引仅保存在内存中。
- 更新检查仅读取 GitHub 公开的 Release 源，不上传图片、不建立云端索引、不包含账号系统与遥测；工作区内容始终留在本机。

## 当前边界

v0.0.2 是第二个公开预览版本，以下能力尚未完成：

- 工作区不会实时监听磁盘变化，重新打开文件夹可刷新索引。
- 缩略图缓存暂未设置容量上限与自动淘汰策略。
- Windows 上的 HEIC/HEIF 支持仍不完整，建议先转换为 JPEG 或 PNG。
- 安装包尚未进行 Apple 公证与 Windows 代码签名。
- 自动更新目前只提示新版本并跳转下载，不支持应用内静默安装。
- 暂不包含相册、标签、编辑、重复图片检测或云端同步等资产管理功能。

## 开发

环境要求：Node.js 22.12+、npm 10+。

```bash
npm ci
npm run dev
```

常用检查与构建：

```bash
npm run typecheck   # TypeScript 类型检查
npm run build       # 构建 Electron 主进程、预加载层与渲染层
npm run build:mac   # 在 macOS 上生成当前架构的 DMG 到 release/
npm run build:win   # 在 Windows 上生成 NSIS 安装包到 release/
```

如果 Electron 或 electron-builder 的二进制下载受限，可使用镜像：

```bash
ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ \
ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/ \
npm run build:mac
```

### 自动发布

推送 `v*` 标签会触发 GitHub Actions：

1. 在 macOS Apple Silicon、macOS Intel 与 Windows 64 位环境分别构建。
2. 上传 `.dmg` 和 `.exe` 安装产物。
3. 自动创建对应的 GitHub Release。

```bash
git tag v0.0.2
git push origin v0.0.2
```

## 项目结构

```text
src/
  main/       Electron 主进程、目录扫描、图片协议、缩略图缓存
  preload/    受控的 IPC 接口
  renderer/   React 界面、虚拟化布局、搜索 Worker、图片查看器
  shared/     主进程与渲染层共享类型
resources/    应用图标
```
